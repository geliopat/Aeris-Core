# Aeris — спецификация интерфейса WinUI 3

Позднее утверждённые простой и полный макеты имеют приоритет над исходным дизайном FlClashZ. Макеты в обсуждении были демонстрационными; состояние кода отдельно в [STATUS.md](STATUS.md). Все страницы используют фактический FlClashZ как визуальный и функциональный эталон, адаптированный к WinUI 3; поздние явно утверждённые отличия Aeris имеют приоритет. Не копировать исходники без проверки лицензии.

## 1. Общий дизайн

C#/XAML WinUI 3. MVVM и CommunityToolkit.Mvvm — исходные проектные кандидаты для соответствия утверждённому UI и измеряемой производительности. Native AOT при совместимости; без Flutter/Electron/WebView2 в основном UI. Fluent, адаптивность, high DPI, RU/EN. Два режима, только по заголовку `providermode` (полный) или его отсутствию (простой); без ручного переключателя. Режим перестраивается при смене/обновлении профиля, не меняет логику ядра. Виджеты фиксированы, редактора нет.

По умолчанию системная тема/цвета, Acrylic для окна и карточек, 60% НЕпрозрачности (40% прозрачности). Независимые цвет фона, карточек, акцент; sidebar/text/selected/hover при необходимости; отдельная непрозрачность фона/карточек; HEX/RGB, wallpaper, радиусы/плотность, проверка контраста. Mica/Mica Alt/Acrylic/Solid с нативными ограничениями и безопасным fallback на Windows 10/отключённых эффектах; Mica не обещает настоящую прозрачность. Light/Dark/AMOLED — неизменяемые встроенные пресеты, редактируемая копия, именованные темы JSON import/export. Независимая синхронизация параметров с системой, sync-all, назначение своих light/dark тем на смену ОС, live preview без restart. Нет новых заголовков персонализации.

Без видимых рамок окна, карточек, sidebar и блоков. Нативные скругления, тень, кнопки заголовка, drag/resize/Snap где поддержано. Выбранный элемент — оттенок и/или check, без обводки. Свечение всех кликабельных текстовых кнопок, иконок, ссылок при hover/focus, цвет элемента, 180 мс, настройка интенсивности/отключение, без собственного фона/рамки; не для disabled. В состоянии покоя свечение отсутствует; общий стиль всех кликабельных элементов, включая текст, иконки и ссылки. Не отменяет необходимой клавиатурной доступности. Анимации: нажатие 100 мс, переход страницы 150, раскрытие 180, toggle VPN/DPI 200, статус 150, sidebar/theme 200; системный/on/off, default system; без анимации каждого обновления статистики.

## 2. Простой режим — фиксированный дашборд

Навигация: Главная, Прокси, Профили, Zapret2, Диагностика; Настройки закреплены внизу. О программе внутри настроек внизу. Скрыты Соединения, Маршрутизация, DNS, Журналы, технические настройки, статистика sidebar и конфигурационные редакторы. Упрощённые Zapret2, диагностика и настройки.

Карточки сверху вниз:
1. VPN: большая круглая кнопка в центре, загрузка зелёным слева и отдача синим справа, статус над, таймер/подсказка под. Только VPN toggle.
2. Подписка сразу под кнопкой: название вместо слова «Профиль», кнопки смены, «Обновить подписку» (компактный текст + icon в верхней строке, без фона), сайт, поддержка; трафик, срок и прогресс. Текст announce полностью в этой же карточке, без заголовка, отдельной иконки, фона, разделителя или сворачивания, со ссылками/переносами. При отсутствии данных соответствующие элементы исчезают.
3. Сервер: крупный круглый флаг фактического выхода, название/страна, выбранная группа, ping; IP всегда скрыт. Переход на полноценную страницу Прокси к выбранной группе, никакого dropdown или выдвижной панели.
4. Zapret2: независимый переключатель, статус, активная/выбранная стратегия, время работы, 4 HTTPS-проверки: YouTube, GoogleVideo, Discord Gateway, Discord Voice API; ручное обновление. Стратегия открывает полноценный раздел Zapret2 → Стратегии. Никаких всплывающих селекторов. Voice API не равно UDP voice.

Нажатие на название/смену подписки открывает Профили. Обновление подписки/пингов — без перехода. Нажатие на результат проверки Zapret2 открывает полноценный раздел тестирования; кнопка обновления лишь повторяет проверку. VPN и DPI управляются независимыми переключателями, без скрытого изменения состояния другого модуля. Клиент не обещает обновление до фактического результата. Верхние индикаторы ядра и Zapret2 доступны для отдельных перезапусков. Нет графика/ресурсов в простом режиме. 

## 3. Полный режим (ProviderMode) — фиксированный макет

Sidebar сверху: название активной подписки без иконки папки и слова «Профиль», четыре равные иконки (смена профиля, обновить без текста, сайт, поддержка), трафик/срок/индикатор. Нет анонса. Средняя зона: Главная, Прокси, Профили, Соединения, Маршрутизация, DNS, Zapret2, Журналы. Отдельного пункта «Диагностика» нет. Нижняя зона: компактные блоки диагностики, трафика, ресурсов; Настройки всегда у самого нижнего края, шестерёнка при collapsed. Заголовок «Диагностика» кликабелен и открывает полную страницу; icon запускает проверку на месте. Отображаются ядро/VPN/DNS/Zapret2/маршрутизация/служба: цвет названия компонента соответствует согласованной палитре журналов, статус отдельно различим текстом и не только цветом. Отключённые по воле пользователя модули не ошибки. Трафик: текущие скорости, компактный график, объём за сеанс; ресурсы: CPU, общая RAM, ядро/GUI/служба. Блоки без собственных фонов и линий; плотные строки 0–2 DIP, padding около 8 DIP, график 40 DIP, межблочный интервал около 12 DIP, пункты навигации около 28 DIP; размер шрифта не уменьшать. При небольшой высоте обеспечить доступность и не обрезать Настройки. Sidebar сохраняет состояние, статистика не прокручивается вместе с контентом страницы.

Дашборд справа:
1. VPN как в простом + режим маршрутизации (Правила/Глобальный/Прямой с учётом `noglobal`; другие утверждённые режимы в соответствующих настройках).
2. Сервер: флаг, группа, название, страна, протокол, выходной IP всегда виден при наличии, пинг. Переход в Прокси.
3. Zapret2: как в простом + режим обработки.
4. Соединения: отдельная карточка, активные TCP/UDP, proxy/DIRECT, переход на страницу Соединения.
5. DNS: отдельная карточка, задержка DNS, резолвер, cache hit, ошибки, переход на страницу DNS.
6. Маршрутизация: число правил/наборов/ошибок, переход в раздел.

Нет карточки подписки, анонса, proxy-групп, графика трафика, ресурсов или отдельной карточки состояния компонентов на дашборде. Адаптивные колонки при достаточной ширине; верхние независимые кнопки restart ядра/Zapret2. Настройки и состояние не сбрасываются при смене режима.

## 4. Страницы

**Прокси.** Эталон фактических list/tab FlClashZ: adaptive 1–3 колонки групп ориентир 360 DIP, независимая высота колонок, распределение групп round-robin в исходном порядке, сворачиваемость, tabs горизонтальные chips. Настройки list/tab, sort none/delay/name, layout loose/standard/tight, card loose/standard/compact/oneline, icon filled/plain/hidden, hide timeout. Карточка узла: имя, описание/фактический leaf, latency, выбор/check, повторный тест кликом на задержку, выбор selector и pin/unpin автоматических групп. Поддержка hidden/groupDescription/user SVG/group order, сохранение unfold/scroll/selected per profile, scroll-to-selected, тест all/group/node и dedup node+URL, queued/running. `onegroup`, Rule/Global; учитывать заголовок view. Контекстные функции только допустимые; не редактировать провайдерские группы. Нет постоянной правой панели и лишних графиков. Виртуализация.

**Профили.** Адаптивные карточки, URL/YAML/QR/clipboard/local, трафик/expiry, reorder, sync individual/all, автообновление, HWID, preview read-only, export/copy URL/QR если поддержано, AGE encrypted config при подтверждённой совместимости, history/rollback/diff/validate/update route/secure URL. Нет override YAML подписки, nooverride отсутствует; локальные правила отдельны. Ошибки не заменяют рабочий профиль.

**Соединения (полный).** Три верхние вкладки: Активные, Недавние запросы, Zapret2 (standalone тоже). Компактная таблица FlClashZ, чередование нейтральных строк, resize/sort/filter/search, detail flyout, close individual/all/app при поддержке, virtualize и обновления ~1s. Столбцы process, target, protocol, rule, outbound, DPI отдельно, dl/ul rates/totals, duration. DPI tab process/target/TCP UDP/strategy/list/packets/traffic/duration. Цвет только текста, не badges или цветной фон. TCP #529DFF, UDP #FF922B, ICMP #20C9C3, DIRECT #39D353, Zapret2 #B478FF, REJECT #FF4848. Серверные цвета стабильны, отличимы от системных и протокольных, с учётом темы; ручные overrides цветов optional. Не гарантировать сотни уникальных цветов.

**Маршрутизация (полный).** Rules/Providers/Geodata. Провайдерские правила read-only; пользовательские добавлять/edit/reorder/disable/delete с приоритетом. Источник, порядок, simulation/conflicts/hits; providers индивидуальное/общее обновление, дата/count/size/mirror/search/view/rollback. Нет редактора общего YAML.

**DNS (полный).** Overview/Settings/Cache/Queries (при включении). Резолвер/маршрут/latency, restart, manual query, независимая очистка DNS и Fake-IP, leak diag/policies. Настройки ядра подписки read-only; клиентские функции и разрешённые настройки отдельно. Без AdGuard/recursive и лишних графиков.

**Zapret2.** Полный: Strategies/Lists/Autoselect/Components/Settings, группы Flowseal на Zapret2/Zapret2/Ultimate/custom, режимы, списки include/exclude/auto/source/conflicts, независимое обновление совместимых ресурсов, history и four probe results; параметры проверок, таймауты и порты настраиваемы в полном режиме, точные пределы и значения проверяются по эталону. Простая версия: on/off, выбор стратегии, автоподбор; без редакторов Lua/BAT и сложных параметров. Ручной выбор в списке, активная и выбранная различаются при необходимости. Статусы ошибок/частичного успеха/непроверенного результата; не подменять Voice API UDP-проверкой. Логи и соединения отдельно.

**Журналы (полный).** Все/Ядро/VPN/DNS/Zapret2/Маршрутизация/Служба, time/level/component/message, filter/search/pause/autoscroll/copy/export/clear, memory/file/limit/redact/virtualize. Имена компонентов в tabs и общей колонке цветом: Core #FFDF32, VPN #529DFF, DNS #20C9C3, DPI #B478FF, routing #FF922B, service #FF69B4. Уровни error красный/warn оранжевый/info зелёный/debug синий/trace серый. Без цветных фонов и рамок. Default warn memory, disk off.

**Диагностика.** Полный: компактные строки компонентов, check all/individual, status/details/recommendation/restart/scrubbed export, direct/vpn test цели, leak и network tests вручную, лёгкий health автоматически, без автоматического ремонта. Простой: общая проверка, понятные рекомендации. Пункт в простой навигации, в полном — кликабельный нижний заголовок sidebar.

**Настройки.** Application, Personalization, VPN/TUN, Network, Performance, Security, API, Updates, Advanced, О программе внизу. Общий backup/restore исключён; не дублировать DNS/Zapret/маршрутизацию. Простой: язык, внешний вид, автозапуск, уведомления, необходимые безопасные настройки. Полный: расширенные разрешённые параметры, не редактирование YAML подписки. О программе: logo/name/version, большая check update button и progress, технические сведения раскрываемые (core/service/driver/API/IPC/TLS/CPU/build/channel/refs), changelog, репозитории, лицензии, авторы, report bug.

## 5. Трей и поведение

Меню строго VPN on/off и Zapret2 on/off, тонкий нейтральный разделитель, restart VPN/restart Zapret2, разделитель, открыть/выход. Без stats/profile/server menu; тема, Acrylic 60% где поддержано, borderless. Left click показать/скрыть, right menu, middle configurable если сохранено; tooltip статуса/скорости; цвет значка offline gray/VPN blue/DPI purple/both green/error red. Закрытие в трей default on; exit корректно останавливает компоненты по принятому сценарию. Автозапуск Windows, запуск в трей и запуск свёрнутым — отдельные настройки, все по умолчанию off. Один GUI экземпляр, URI scheme, YAML association default off, sleep/network recovery on.

Уведомления Windows/внутри UI: default on для аварии VPN/core/service/DNS/DPI, update app, expiry/quota, subscription update error, Kill Switch; off для manual toggles, auto server/strategy change, component updates. Категории отдельно, dedup, click opens section, no extra notification center. Native toast style ОС, не имитировать Acrylic там.

Hotkeys: toggle VPN/DPI, restart each, show/hide; все не назначены и global off по умолчанию, отдельный global switch per action. Не использовать постоянный keyboard hook, проверять конфликты; изменения применяются сразу, без перезапуска. Глобальные и локальные сочетания различать; конфликт не перехватывать молча.

Первый запуск: disclaimer один раз: подтверждение сохранять в той же локальной директории настроек Aeris, не в отдельном ключе реестра; обычный перезапуск и обновление не повторяют запрос. Системный язык, простой dashboard add subscription; без регистрации и tour. Подписка задаёт mode. Запоминать profile/selected proxies/strategy/routing/window/sidebar/unfold/theme; открывать Главная, не последнюю страницу. VPN/DPI independently never/restore/always, default never если не задан поддержанный заголовок (Zapret2). При сбое GUI ядро не прерывается. Offline UI работает для подписок/выбора/персонализации/локальных правил/истории/обновлений/диагностики; ping требует нужный модуль, active connections недоступны без соответствующего модуля.

Confirm: удалить профиль/стратегию/правила, закрыть все соединения, reset, удалить службу/driver, внешние ссылки. No confirm: обычные toggles/restart/select, clear logs/cache, exit. RU/EN, system language default, fallback English, no restart, локализованные даты/время, МБ/с или Мбит/с, имена групп/стратегий/анонсы не переводить.

## 6. Производительность GUI

Событийный IPC; трафик 1s, CPU/RAM 2s, состояния немедленно; незримые страницы не отрисовывать, pause graphs/animations minimized, tray stops rendering, lazy load/virtualize, SVG/flags cache. Сетевые проверки независимо от rendering; не ограничивать ядро из-за GUI. При потере IPC не зависать, синхронизация после восстановления.

## 7. Границы будущих расширений

Сохранять разделение интерфейса, состояния и версионируемого IPC с ядром. Оставлять возможность добавления точек WinUI 3 после стабилизации. Контракт выбирается на этапе модулей. Текущие макеты, навигация и базовый клиент работают независимо от дополнительных модулей. Сторонний код не получает прямого доступа к привилегированным ядру и службе.
