# Значения по умолчанию / Defaults

Утверждённые defaults из обсуждения и основных документов. TBD означает не согласовано или зависит от проверки; не вводить скрытый fallback. Сетевые настройки профиля не меняются GUI.

| Область | По умолчанию |
|---|---|
| ОС / архитектура | Windows 11 x64 основная; Windows 10 22H2 x64 также обязательна |
| Режим GUI | Простой без providermode, полный с флагом; без ручного переключателя |
| IP / announce | IP только полный при наличии; announce только простой |
| Тема / цвета | Системные, окно и карточки Acrylic, 60% непрозрачности |
| Анимации | Системная настройка; hover 180 ms, click 100, page 150, expand 180, toggle 200, status 150, sidebar/theme 200; нет idle glow |
| Язык | Системный RU/EN, fallback EN; менять без перезапуска |
| Горячие клавиши | Не назначены; global off для каждого действия |
| Запуск Windows / в трей / свёрнутым | Off, отдельные настройки |
| Закрытие окна | В трей on |
| Стартовая страница | Главная; не сохранять последнюю посещённую |
| Single instance / URI | On; aeris:// |
| Ассоциация YAML | Off |
| Восстановление после сна/смены сети | On |
| VPN и DPI при старте | Независимо never/off; restore/always по настройке, DPI может использовать согласованный header |
| HWID | Простой always on без выключения; полный default on, можно выключить |
| TUN | RIPS после подтверждения стабильности; до этого не объявлять готовым |
| DNS | Системный только при явной настройке; резерв только заданный; hijack standard + fail-closed |
| Kill Switch | proxy-only; точная семантика в контракте TBD |
| DPI | Подходящий DIRECT по спискам; VPN-транспорт исключён; standalone возможен |
| Автоподбор DPI | Сохранять историю; применение выбранного результата вручную по умолчанию |
| Сетевой профиль DPI | Ручной выбор по умолчанию; наблюдение/автоопционально |
| API | Локальный, remote off; отдельные полномочия и ACL |
| Общие логи | warn, memory 8 MB, disk off |
| DNS логи | memory 4 MB, ошибки/безопасность, полные запросы off |
| DPI логи | basic memory 4 MB, Lua warn/trace off |
| История соединений | Off; live/aggregate on; при включении SQLite 7 дней/100 MB, настраиваемо |
| Автоподбор | История on |
| Обновления | Release; check каждые 24 ч, клиент/core по согласию, ресурсы по настройкам, драйверы с подтверждением |
| Уведомления on | Аварии компонентов, DNS/DPI ошибки, обновление приложения, expiry/quota, ошибки обновления подписки, Kill Switch |
| Уведомления off | Ручные toggle, автоматическая смена узла/стратегии, обновления компонентов |
| GUI refresh | Traffic/connections 1s; CPU/RAM и агрегаты 2s; status event сразу |
| Подтверждение | Удаление профиля/стратегии/правил, close all, reset, удаление службы/драйвера, внешние ссылки |
| Без подтверждения | Toggle/restart/select, clear logs/cache, exit |

Численные сетевые таймауты, размеры буферов, алгоритм кэша, размеры пулов и другие параметры, установленные только как начальные инженерные значения в коде, не считать согласованными пользовательскими defaults. Точные значения benchmark-driven; не добавлять выдуманные YAML поля.
